# 그림톡톡! (DRAW & GUESS)

6학년 영어 수업용 갈틱폰식 문장 ↔ 그림 전달 게임 (단일 HTML).

- 주소: https://seoyuha.github.io/grimtoktok/
- 선생님: 첫 화면 → [방 만들기] → 모드·단원 문제 고르기 → 모둠 자동 배정 → 시작
- 학생: 첫 화면 → [방 찾기] → 4글자 코드 입력 → 캐릭터·이름 → 입장
- 모드 11종: 일반 릴레이 · 제시 문장 · 아이스브레이커 · 넉오프 · 비밀 · 애니메이션 · 협동 · 샌드위치 · 스토리 · 조각 이어그리기 · 문제 맞추기
- 데이터: Firebase Realtime Database (`doodle` 경로)
- 체험 모드: 주소 끝에 `?local=1` 을 붙이면 한 기기의 탭끼리만 연결돼요.
